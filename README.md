# Underground-Cable-Fault-Detection-Using-Arduino

1. Project Overview

This project focuses on detecting faults in underground electrical cables using Arduino. It helps identify the approximate location of a cable fault by measuring changes in resistance and displaying the fault distance.

2. Objectives

- To detect faults in underground electrical cables.
- To identify the approximate distance of the fault.
- To reduce the time required for manual fault detection.
- To provide a simple and cost-effective fault detection system.

3. Components Used

- Arduino Board
- Resistors
- Connecting Wires
- Breadboard
- LCD Display
- Power Supply
- Underground Cable Fault Simulation Setup

4. Working Principle

The system works on the principle of resistance variation. When a fault occurs in the cable, the resistance changes. The Arduino reads the corresponding voltage variations and estimates the distance of the fault. The detected distance is displayed on the LCD.

6. Applications

- Underground electrical cable fault detection.
- Electrical maintenance systems.
- Power distribution networks.

7. Project Status

Academic project completed as part of the 6th semester of Bachelor of Engineering in Electronics and Communication Engineering.

9. Conclusion

This project demonstrates a simple approach to detecting underground cable faults and estimating their locations, helping improve the efficiency of electrical cable maintenance.
